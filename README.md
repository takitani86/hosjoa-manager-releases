# Hosjoa Manager

**UChat 채팅에서 받은 YouTube 영상 신청을 PotPlayer 재생목록에 연결하는 Windows 프로그램입니다.**

시청자가 채팅에 YouTube 링크를 보내면 신청을 접수하고, 대기 순서에 따라 실행 중인 PotPlayer에 전달합니다.

## 다운로드

👉 **[최신 버전 다운로드](https://github.com/takitani86/hosjoa-manager-releases/releases/latest)**

릴리스 페이지의 **Assets → HosjoaManager.exe**를 다운로드하세요.

이 저장소는 실행 파일과 업데이트 안내를 제공하는 배포용 저장소입니다.

## 주요 기능

- **채팅 신청 접수** — YouTube 링크 한 개 또는 `!신청 링크`로 신청
- **영상 정보 표시** — 신청 내역에서 영상 제목과 썸네일 확인
- **대기 순서 변경** — 대기 중인 신청을 드래그하여 정렬
- **신청 내역 관리** — 최대 100건 보관, 우클릭으로 삭제·링크 복사·YouTube 열기
- **PotPlayer 자동 감지** — 실행 중인 플레이어에 연결하고 신청 영상 전달
- **신청 결과 안내** — 접수·중복·주소 오류를 신청자에게 귓속말로 안내
- **닉네임 블랙리스트** — 지정한 닉네임의 새 신청 무시
- **자동 업데이트** — 새 버전 자동 확인·다운로드, 원하는 시점에 적용

## 사용 환경

- Windows 64비트
- 같은 PC에서 실행하는 PotPlayer
- Microsoft Edge WebView2 Runtime
- 인터넷 연결

## 시작하기

1. `HosjoaManager.exe`를 쓰기 가능한 폴더에 저장하고 실행합니다.
2. **UChat 채팅방 ID**와 **봇 닉네임**을 입력합니다.
3. **연결**을 눌러 채팅방에 접속합니다.
4. PotPlayer를 실행하고 재생목록을 열어둡니다.
5. 연결 상태를 확인한 뒤 영상 신청을 받습니다.

채팅방 ID는 웹페이지 주소가 아닌 UChat의 `room` 값입니다.

PotPlayer는 한 개만 실행해주세요. 프로그램에서 자동으로 찾으며, 실행 중인 플레이어가 없으면 **PotPlayer 실행** 버튼을 사용할 수 있습니다.

## 영상 신청 방법

채팅에 YouTube 링크 한 개를 보내거나 다음 형식으로 신청합니다.

```text
!신청 https://www.youtube.com/watch?v=영상ID
```

운영자는 관리 창의 **주소 추가**로 직접 신청할 수도 있습니다.

대기 중인 영상은 드래그로 순서를 바꿀 수 있습니다. 이미 전달되었거나 재생 중인 영상은 PotPlayer에서 관리해주세요.

**확인 필요** 항목은 내역에 남겨두고 다음 대기 신청을 처리합니다. 해당 영상의 실제 추가 여부는 PotPlayer에서 확인할 수 있습니다.

## 업데이트

새 버전은 앱 실행 시와 6시간마다 자동으로 확인하고 다운로드합니다.

다운로드가 완료되면 **업데이트 및 재시작** 버튼을 눌러 적용하세요. 자동 다운로드만으로 프로그램이 재시작되지는 않습니다.

- 적용 중에는 봇 연결과 신청 수신이 잠시 중단됩니다.
- PotPlayer 재생은 유지됩니다.
- 업데이트 파일의 서명과 무결성을 검증합니다.
- 새 버전의 시작에 실패하면 이전 EXE로 복구합니다.

**0.4.x 사용자는 처음 한 번 EXE를 직접 교체해야 합니다.** 앱을 종료하고 새 파일로 교체한 뒤 실행해주세요.

## 데이터 보관과 종료

설정·신청 내역·블랙리스트·채팅 접속 데이터는 실행 파일 옆의 **`HosjoaManager.Data`** 폴더에 저장됩니다.

업데이트할 때 이 폴더를 유지해주세요. 다른 폴더로 옮길 때도 EXE와 함께 이동하면 기존 데이터를 이어서 사용할 수 있습니다.

관리 창의 **X** 또는 트레이 메뉴의 **종료**를 누르면 프로그램과 봇 연결이 완전히 종료됩니다. PotPlayer는 계속 실행됩니다.
